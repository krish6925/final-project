# 🎯 Goal Tracker

> A full-stack MERN application for managing and tracking employee goals throughout their complete lifecycle.

## 🚀 Features

- 🔐 JWT-based authentication and role-based authorization
- 👤 Separate access for Employees, Managers, and Admin/HR
- 🎯 Create, update, delete, and track goals
- ✅ Manager approval and rejection workflow
- 🔒 Goal locking after approval
- 📊 Role-based dashboards
- 🔄 Shared Goals for departmental objectives

## 🛠️ Tech Stack

| Technology | Used For |
|------------|----------|
| ⚛️ React.js | Frontend |
| 🟢 Node.js | Backend |
| 🚂 Express.js | API Development |
| 🍃 MongoDB | Database |
| 🔑 JWT | Authentication |
| 🔒 bcrypt | Password Hashing |

## 📌 Overview

Goal Tracker provides a centralized platform where employees can create and track goals, managers can review and approve them, and administrators can monitor overall goal progress.
